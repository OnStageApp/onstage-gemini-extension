# OnStage

OnStage is a service planning platform for churches. These tools act on the one team the user picked when they signed in to OnStage.

- Call the team context tool first to learn the team's members, groups and positions.
- Dates and times are the team's local time, written without an offset (for example 2026-11-01T10:30).
- Song and event uploads are previewed first and applied only after the user confirms.
- Talk about events, songs and people by name. Never show ids.
